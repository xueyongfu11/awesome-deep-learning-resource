# DMA、RDMA、TCP 与零拷贝

## 1. DMA 与 RDMA

DMA 是设备直接搬运内存数据的机制。CPU 准备缓冲区、描述符和任务，设备执行数据搬运，CPU 不必逐字节复制。例如网卡通过 DMA 把收到的数据写入本机内存。

RDMA 将直接内存访问扩展到跨机器通信。应用准备并授权内存后，两端 RNIC 可以完成跨网络的数据传输。典型单边 Read/Write 不需要远端 CPU 为每次操作执行接收与复制逻辑。

| 项目     | DMA                          | RDMA                           |
| -------- | ---------------------------- | ------------------------------ |
| 主要范围 | 本机设备与内存               | 跨机器内存访问                 |
| 执行主体 | 支持 DMA 的设备或控制器      | RNIC 与相应传输协议            |
| 访问控制 | DMA 地址映射，可能经过 IOMMU | 内存注册、权限、访问密钥等     |
| CPU 工作 | 配置、提交、完成处理         | 连接与资源管理、提交、完成处理 |
| 应用     | 磁盘、网卡、加速卡数据搬运   | 分布式计算、存储、KV 传输      |

普通网卡也用 DMA，但不一定支持 RDMA。RDMA Send/Receive 需要接收端预先准备接收缓冲区，不能直接套用单边 Read/Write 的描述。

## 2. TCP 与 RDMA 的典型数据路径

TCP 是可靠有序的字节流协议，RDMA 是远程内存访问机制，两者并非完全同层概念。工程上通常比较传统 TCP Socket 与硬件 RDMA 数据路径。RDMA 的承载包括 InfiniBand、RoCE、iWARP；其中 iWARP 本身就使用 TCP。

```text
传统 TCP 常规复制路径：
A 应用 → A 内核缓冲区 → 网卡 → 网络 → 网卡 → B 内核缓冲区 → B 应用

RDMA 已注册缓冲区路径：
A 应用缓冲区 → RNIC → 网络 → RNIC → B 已注册的应用缓冲区
```

| 项目     | 传统 TCP Socket              | 硬件 RDMA                        |
| -------- | ---------------------------- | -------------------------------- |
| API      | send/recv 字节流             | Send/Receive、Read/Write 等      |
| 协议处理 | 主要依赖内核，部分能力可卸载 | 大量处理由 RNIC 完成             |
| 内核参与 | 常规收发需要进入内核         | 资源建立后数据路径通常可旁路内核 |
| 数据复制 | 常规路径有用户态与内核态复制 | 可直接访问注册的应用缓冲区       |
| 远端软件 | 通常参与接收                 | 单边操作无需逐次执行接收逻辑     |
| 部署     | 通用性强                     | 需要相应软硬件和网络配置         |

## 3. RDMA 为什么通常更快

1. 减少中间复制，节省 CPU、内存带宽与缓存资源。
2. 减少数据路径中的系统调用、唤醒和调度开销。
3. 通过 RNIC 卸载大量协议处理；可靠传输中的顺序、确认和重传等工作可由硬件承担。
4. 单边操作减少远端软件参与。

这些优势主要降低端点开销，并不提高相同物理链路的速率。若 TCP 已跑满链路，RDMA 可能主要节省 CPU，而不是继续增加吞吐。

连接和内存注册有成本；轮询完成队列也会占 CPU。拥塞、丢包、PCIe、内存带宽及缓冲区设计都会影响实际收益。TCP 也有零拷贝和硬件卸载，不能说它必然需要全部中间复制。

## 4. 零拷贝到底省掉什么

零拷贝指在指定路径中避免不必要的数据复制，尤其是 CPU 在不同缓冲区之间的复制；不代表数据完全不移动。

```text
常规发送：应用缓冲区 ──CPU复制──→ 内核缓冲区 ──DMA──→ 网卡
零拷贝发送：应用缓冲区 ─────────────DMA──────────→ 网卡
```

DMA 只说明设备承担搬运，不保证整条链路没有中间复制。RDMA 也不保证应用没有先把数据复制到临时注册缓冲区。

异步零拷贝还要求管理缓冲区生命周期：确认硬件不再访问前，不能随意修改、释放或复用。远端数据何时可被应用消费，也需要正确同步。

判断“零拷贝”时应问：哪两个位置之间的哪一次复制被省掉了？

## 5. 放到推理集群中理解

- 本机 CPU 与加速卡之间搬运 KV，涉及设备数据传输和 DMA。
- 跨节点搬运 KV 可以使用 RDMA。
- 网卡直接访问 GPU 显存，还需要 GPUDirect RDMA 等能力以及拓扑、驱动支持；RDMA 本身不自动意味着显存直传。
