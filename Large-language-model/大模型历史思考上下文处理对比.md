# 大模型会保留历史思考吗？主流模型的上下文处理规则对比

同样是推理模型，上一轮生成的思考内容，在下一轮对话中是否还会进入上下文？不同模型、不同版本，甚至同一模型的本地模板与 API，处理规则都可能不同。

本文对比 Qwen、DeepSeek、MiniMax、Kimi、GLM、gpt-oss 和 Gemma 的历史思考处理方式，重点区分跨用户轮次的历史思考与当前问题内的工具链思考，并整理对应的控制参数、默认值和官方依据。

> 核对日期：原有条目为 2026-10-08；GLM-5.3 / GLM-5.3-Flash、gpt-oss、Gemma 4 为 2026-10-29。具体部署应以实际使用的模型版本、模板版本和服务商实现为准。

## 先区分两种“保留思考”

本文所说的“保留思考”，指历史思考文本是否被拼入下一次模型输入，与界面是否显示、日志是否保存无关。

- **跨用户轮次**：新用户问题到来后，上一轮的思考是否继续进入上下文。
- **当前工具链**：同一个用户问题中，assistant 调用工具、接收结果并继续推理时，中间思考是否保留。

例如，对话历史是：

```text
用户 U1 → 思考 T1 → 答案 A1 → 用户 U2
```

- 删除旧轮次思考：回答 U2 的输入包含 `U1 + A1 + U2`，不包含 `T1`。
- 保留旧轮次思考：回答 U2 的输入包含 `U1 + T1 + A1 + U2`。
- 当前工具链保留：在 U1 之后、U2 到来之前，assistant 调用工具并继续推理时，可以保留这些中间思考；这不等于跨用户轮次保留。

## Qwen：历史保留开关与默认值的变化

| 版本                 | 已核实的规则                                                                       |
| -------------------- | ---------------------------------------------------------------------------------- |
| Qwen3.5 开放权重模板 | 旧用户轮次思考删除，当前工具链思考保留；没有全历史保留开关                         |
| Qwen3.6 开放权重模板 | 延续上述默认行为，增加 `preserve_thinking=true` 全历史保留                       |
| Qwen3.7 API          | 支持 `preserve_thinking`，默认关闭；此结论不代表存在对应的开放权重模板           |
| Qwen3.8 开放权重模板 | 全历史保留改为默认开启；`preserve_thinking=false` 回到旧轮次删除、当前工具链保留 |
